Rubric

How scoring works

The full rubric, every prompt and worked examples are in docs/METHODOLOGY.md.

Reading

  • CER over Unicode code points after NFC, zero-width removal and quote/dash folding; subset score 100·(1−CER).
  • Inscriptions, palm leaves and Tamil-Brahmi ignore word spacing, the puḷḷi and e/ē–o/ō length — conventions scribes did not mark.
  • The real palm leaves (CICT Tirukkural Ground Truth Corpus, Central Institute of Classical Tamil) are scored against the scribe's own spelling: reciting the canonical Tirukkural is an error.

Identification & translation

  • Script and medium ID: one label from a closed list; anything else counts as wrong; macro-F1.
  • Translation: corpus chrF++ (character 6-grams, word 2-grams, β = 2) against one reference.
  • 95 % intervals on every subset score from a cluster bootstrap over source texts; rank differences are tested with paired resampling.

Aggregation

  • Track = mean of its subsets. Overall = mean of 8 tracks. OCR/HTR = mean of the 6 reading tracks.
  • Tasks a system does not perform are “—”, never zero. Refusals and errors score as empty answers.
  • Same images, prompts and scoring for every model; settings such as reasoning effort are fixed per entry.

Evaluate a model

Clone the repository, set the provider's key, run, and open a pull request with the results directory.

# install (Python ≥ 3.10)
pip install -e ".[dev]" anthropic
# frontier APIs — keys come from the environment
ANTHROPIC_API_KEY=… tamilbench run --model claude-opus-5-5
OPENAI_API_KEY=…    tamilbench run --model gpt-6-astra
GEMINI_API_KEY=…    tamilbench run --model gemini-3-8-flash
# open weights behind vLLM / SGLang / Ollama
tamilbench run --model "compat:Qwen/Qwen3-VL-30B-A3B-Instruct?base_url=http://localhost:8000/v1"
# any other system: run it yourself, then import its answers
tamilbench import-predictions --model my-ocr --file answers.jsonl
